- `base.js` defines the abstract `PlatformAdapter` class exposing getters (`id`, `runtimeRoot`, `managedRoot`, `commandRoot`, `skillsRoot`, `workflowsRoot`, `agentsRoot`, `stateFile`, `instructionFile`) and content-transform hooks (`commandFilename`, `renderCommandContent`, `transformSkillContent`, `transformAgentContent`) plus lifecycle hooks (`inspect`, `planRuntimeFilesSync`, `planRuntimeFilesRemoval`, `inspectRuntimeFiles`, `removeRuntimeFiles`).
- Each host is a single file (`claude.js`, `codex.js`, `cursor.js`, `kiro.js`, `qoder.js`) extending `PlatformAdapter` and overriding only the fields and transforms specific to that host; defaults in the base class cover shared behaviour.
- `index.js` is the registry: it instantiates every adapter once and exposes `getAdapter(id)` / `getSupportedPlatforms()`, so callers never import host files directly.
- `host-native-pointer.js` is a shared helper used by hosts (notably Cursor) that writes/inspects/removes a fenced pointer file inside a host-native rule file, using `buildFileWriteOperation` from `../state` and `formatInitGuidance` from `../init-guidance`.
- Dependency direction is one-way: each adapter depends on `./base` and cross-cutting helpers in `src/cli/*` (`init-guidance`, `skill-path-rewrite-markers`, `state`, `host-native-pointer`); adapters do not depend on each other. Host-specific templates live under `templates/<host>/hooks/` and are read at render time.
