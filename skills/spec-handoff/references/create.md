# Create guidance

Read this reference before creating a handoff. Keep the artifact pointer-first and immutable. Capture only current verified objective, progress, decisions, constraints, blockers, verification and one bounded next-session focus. Attribute statements explicitly as user decisions, verified facts, or writer inference; do not present your inference as user intent. Redact secrets and unrelated personal information. Honor a user-selected destination and do not create an additional managed copy unless requested.
