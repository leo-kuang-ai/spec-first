# Create guidance

Read this reference before creating a handoff. Keep the artifact pointer-first and immutable. Capture only current verified objective, progress, decisions, constraints, blockers, verification and one bounded next-session focus. Attribute statements explicitly as user decisions, verified facts, writer inference, or the writer's own decisions; do not present your inference or autonomous choice as user intent. Redact secrets and unrelated personal information. Honor a user-selected destination and do not create an additional managed copy unless requested.

For each material reference, explain what matters at that path and add a line locator when useful. Describe what exists, what is partial, what is missing, and dependencies between them. Preserve abandoned approaches that a fresh agent might otherwise retry. Choose sections for this session; the artifact-contract examples are not a closed template. Orientation hints may identify useful reads, but carry explicit directives only when the user asked to include them and distinguish them from observed status.

The artifact contract owns the managed location and payload shape; the entrypoint owns writer invocation and the completion receipt. At a user-selected format or destination, retain equivalent orientation metadata where supported without requiring the managed YAML shape. Use an appropriate available capability within the user's authorization. Report fragile worktree or access limitations without preserving or publishing anything implicitly. Quote the final source path when needed in the host-native resume invocation.
