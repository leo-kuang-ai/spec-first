# Craft floor

Apply only what the visual question puts in play. The render must be specific to the product and question, not a generic template or a palette-only variation. Distinct avenues differ by organizing principle, not by superficial spacing or color swaps; the wide-run rule lives in `references/scoping.md`.

For text that is part of the judgment, preserve readable contrast: body text at least 4.5:1 and large text at least 3:1. Check the actual rendered state at the target viewport before recording a decision.

When the question depends on controls or transitions, include usable focus, visible loading/empty/error states and honest action feedback. Use representative content density and copy so overflow, truncation and hierarchy can be judged. Inspect relevant viewport/state pairs; a screenshot of the default state does not validate an interaction. Apply only the parts needed to answer the question, and record limitations when an isolated page cannot reproduce the production context.
