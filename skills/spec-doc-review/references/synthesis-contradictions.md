# 3.5 Resolve Contradictions

Load when retained findings still recommend opposing actions after 3.4; opposing remedies were intentionally kept separate in 3.3. Check each claim against current document text, source, agreed outcomes and constraints first. Disprove or withdraw unsupported claims before asking for a decision; reviewer disagreement alone is not a document defect.

If one supported correction follows from the agreed contract, choose it within existing scope. If an unresolved user commitment or consequential preference remains, combine the opposing remedies into one `manual` finding, stating both views, the missing decision and its effect. Never schedule both remedies as separate edits. Set `finding_type` from the actual error or omission, not from the mere presence of disagreement. Preserve contributing evidence and the reason each claim was retained or rejected.

Continue to 3.5b for one evidence-based `recommended_action`. This judgment grants no edit authority and cannot bypass report-only mode.
