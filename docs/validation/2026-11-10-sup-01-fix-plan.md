# SUP-01 修复计划：linked worktree 原地切换覆盖被忽略文件

**日期：** 2026-11-10  
**问题：** linked worktree 原地切换未保护被忽略的本地文件  
**优先级：** P1  
**Phase：** 1

## 问题分析

### 原始实现问题

**位置：** `skills/spec-worktree/scripts/worktree-manager.sh:688-700`

**原代码（审查发现问题时）：**
```bash
case "$add_mode" in
  remote-branch) git checkout --track -b "$branch_name" "$checkout_ref" ;;
  detached) git checkout --detach "$checkout_ref" ;;
  *) git checkout "$checkout_ref" ;;
esac
```

**问题：** 三条 `git checkout` 路径都缺少 `--no-overwrite-ignore` 标志，允许覆盖被忽略的本地文件。

### 触发条件

- 已处于 linked worktree
- 当前 checkout 有被忽略的本地文件
- 目标分支跟踪同名文件
- 目标分支可切换且未被其他 worktree 占用

### 隔离复现证据

临时仓库场景：
1. main 的 `.gitignore` 忽略 `collision.txt`
2. target 分支跟踪 `collision.txt`，内容为 `target tracked`
3. 从 main 创建 worker linked worktree，写入本地 `user ignored content`
4. 在该 worktree 执行 `isolate target`

**观察结果：** exit 0；分支变为 target；文件内容变为 `target tracked`；用户本地内容被覆盖。

## 修复方案

### 1. 添加 `--no-overwrite-ignore` 标志

**修改位置：** `skills/spec-worktree/scripts/worktree-manager.sh:695-697`

**修复后代码：**
```bash
case "$add_mode" in
  remote-branch) git checkout --no-overwrite-ignore --track -b "$branch_name" "$checkout_ref" ;;
  detached) git checkout --no-overwrite-ignore --detach "$checkout_ref" ;;
  *) git checkout --no-overwrite-ignore "$checkout_ref" ;;
esac
```

**效果：** 三条 checkout 路径都受保护，碰撞时 Git 拒绝切换并返回非零退出码。

- `skills/spec-commit-push-pr/references/branch-creation.md:59` 已使用该标志
- `tests/unit/spec-commit-push-pr-context-contracts.test.js:110-130` 已测试 ignored 碰撞保护
