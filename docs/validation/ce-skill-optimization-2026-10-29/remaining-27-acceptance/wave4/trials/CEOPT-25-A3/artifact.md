The frozen implementation explains these boundaries:

- `scripts/lib/workspace-git-exclude.cjs` resolves and canonicalizes the Git exclude path, checks workspace containment, then writes with `fs.writeFileSync`. Its contract concerns the selected child’s managed exclude block; an `ok=true` result cannot establish correct ownership when the write reaches another file.
- `scripts/lib/git-path.cjs` canonicalizes via the nearest path for which `existsSync` succeeds. Existing links can resolve to another contained file, while dangling leaves can be treated as missing suffixes.
- `scripts/lib/path-safety.cjs` also uses `existsSync` before checking a segment with `lstatSync`. A dangling symlink can therefore escape the link check. The supplementary outside-dangling-leaf receipt demonstrates the resulting external creation.
- `git-path.cjs` invokes Git without a sanitized environment. `workspace-graph-state.cjs` likewise invokes Git through `defaultWorkspaceExec`, which inherits the process environment unless explicitly unset. The polluted-environment and snapshot receipts establish different consequences of this exposure.
- `scripts/lib/source-snapshot.cjs` explicitly removes inherited `GIT_*` variables except `GIT_OPTIONAL_LOCKS` before its Git calls. Its stable snapshot is a bounded positive control, not evidence that the other Git callers are safe.
