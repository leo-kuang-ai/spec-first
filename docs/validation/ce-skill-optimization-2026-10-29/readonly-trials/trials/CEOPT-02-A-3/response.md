Support agents get one **Copy reference** action beside the existing ticket reference, helping them quickly use it while replying to a customer.

Acceptance criteria:

- Activating the action copies exactly the displayed public reference—no customer name, email, internal ticket ID, or extra text.
- A successful copy shows a brief confirmation.
- If clipboard access fails, a clear failure message lets the agent retry; success is never shown for a failed copy.
- The action is reachable and operable by keyboard, with visible focus.

Bulk copy, export, settings, and analytics remain outside scope. No further product decisions are needed for this alignment.
