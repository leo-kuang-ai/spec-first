## 使用规则

1. 新验证任务先按类别取上限；首例超时按 Phase 0 模式处理：**超时不计成功、留档 timeout 记录、按实测校准后重跑**（不静默调大重试）。
2. 每次因超时校准产生的新参数值，回写本表（保持 advisory 性质）。
3. 本文档不替代任何 skill 合同；若与具体验证合同的显式参数冲突，以该合同为准并在此记录差异。

## 已知限制

- 样本仅 2 个超时实例 + 5 次 fresh-source/探查实测；跨模型外推未验证。
- 失效条件：宿主版本或模型显著变更（如 Codex 大版本）后基线需重测。
