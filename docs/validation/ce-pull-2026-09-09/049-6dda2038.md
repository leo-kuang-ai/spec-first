## 实施与差异

- 新增 CommonJS `scripts/decide.cjs`：主指标始终 required；其他 required 任一超阈值改善且无其他必需指标超回退容差即可 eligible。secondary 不参与准入。支持 absolute、relative、paired、judge 改善下限、样本优先聚合、无单位 rank_score 和全部已声明 required target 达标判断。
- 梯度采样区分 promising、inconclusive、censored；请求 smoke/exploratory/add_sample/confirm 时不能集成。确认后的 eligible 也只是数值事实，写入优化分支后才是 kept。未入选的有效实验为 not_selected。组合 runner-up 使用新快照和新样本，保留 standalone 历史。
- schema 是兼容性追加：单主指标、stable/repeat、原 measurement-only calibration 字段保留；新增字段在入口验证、measurement、loop、persistence 和 wrap-up 均有消费者。日志一实验一条，后续采样更新同条但不删除既有原始观测。基线及最终确认用完整协议。
- 上游静默默认/钳制无效阈值和采样计数的行为不适用本地：无效值报 error，不擅改已批准协议。未知枚举、重复名称、非有限目标和负回退边界也拒绝。paired 不重复使用最后一个 baseline 样本；缺配对时不把 scalar judge aggregate 变成配对改善。零基线的恶化仍是回退，不允许其他指标补偿未定义的相对退化。
- `measure.sh` 使用本地 `SPEC_OPTIMIZE_CENSOR_AFTER`，仅限预声明且小于硬超时的正界限。命令自行退出 124/125 与计时器事件分别记录；125 加 `SPEC_OPTIMIZE_CENSORED:` marker 才表示 censor。GNU timeout/gtimeout 保留独立退出状态；Python fallback 支持小数秒、进程组清理及原退出码。无效 censor 设置在命令前失败。
- smoke 和 censor 纳入现有 measurement execution envelope，未授权时不执行；没有新增 worker/模型权限。比较器只计算数学与采样事实，不判断业务价值或授予集成权限。
