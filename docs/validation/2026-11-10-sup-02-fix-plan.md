# SUP-02 修复计划：优化实验共享文件复制在 containment 校验前创建目录

**日期：** 2026-11-10  
**问题：** 共享文件复制在 containment 校验前执行 mkdir，可能在外部创建目录  
**优先级：** P1  
**Phase：** 1

## 问题分析

### 原始实现问题

**位置：** `skills/spec-optimize/scripts/experiment-worktree.sh:385-391`

**原代码（审查发现问题时）：**
```bash
dest_dir=$(dirname "$dest_path")
mkdir -p "$dest_dir"  # 先创建目录
dest_real=$(realpath_for_new_path "$dest_path")
if ! path_within "$dest_real" "$worktree_real"; then
  echo "Error: shared_file destination resolves outside experiment worktree"
  return 1
fi
```

**问题：** `mkdir -p` 在 containment 检查之前执行，如果目标路径解析到边界外，外部目录已被创建。

### 触发条件

- 基线提交中 `shared` 为指向仓库外目录的符号链接
- 当前源树把它替换成真实目录，并提供 `shared/nested/data.txt` 作为 shared file
- 新实验 worktree 从该基线创建，仍保留外部符号链接

### 隔离复现证据

临时仓库场景：
1. 基线提交：`shared` → 外部目录符号链接
2. 当前源树：`shared/nested/data.txt` 真实文件
3. 调用 `create review 1 main shared/nested/data.txt`

**观察结果：** exit 1，报 `destination resolves outside experiment worktree`，但外部目录已出现 `nested/` 子目录。

### 证据边界

- 已证明拒绝前发生越界建目录
- 未证明任意文件覆盖或删除
- 完整 workflow 对触发条件的可达性需继续核对

## 修复方案

### 1. 调整检查顺序

**修改位置：** `skills/spec-optimize/scripts/experiment-worktree.sh:385-393`

**修复后代码：**
```bash
dest_dir=$(dirname "$dest_path")
# SUP-02 fix: verify containment BEFORE creating any directories
dest_real=$(realpath_for_new_path "$dest_path")
if ! path_within "$dest_real" "$worktree_real"; then
  echo "Error: shared_file destination resolves outside experiment worktree: $shared_file"
  return 1
fi

mkdir -p "$dest_dir"  # 只在校验通过后创建
```

**效果：** 
- containment 检查在任何 mkdir 之前执行
- 拒绝时不产生外部副作用
- 通过后正常创建目录并复制文件
