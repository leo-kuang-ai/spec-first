### 阶段 2：自主决策优先级（AI判断）

**目标**：基于全量审查，AI自主决定优化优先级

**决策逻辑**：
```python
def autonomous_decision():
    # 收集所有问题
    all_issues = []
    for skill in all_skills:
        issues = skill.identified_issues
        for issue in issues:
            issue.score = calculate_score(
                frequency=issue.occurrence_rate,  # 出现频率
                severity=issue.impact,            # 影响严重程度
                fixability=issue.fix_difficulty,  # 修复难度
                roi=issue.expected_roi            # 预期ROI
            )
            all_issues.append(issue)
    
    # 按评分排序
    all_issues.sort(by=score, reverse=True)
    
    # 自主分级
    P0 = [issue for issue in all_issues if issue.score >= 8.0]  # 必做
    P1 = [issue for issue in all_issues if 6.0 <= issue.score < 8.0]  # 强烈建议
    P2 = [issue for issue in all_issues if 4.0 <= issue.score < 6.0]  # 可选
    
    # 自主决策
    total_effort = sum([issue.fix_hours for issue in P0 + P1])
    if total_effort <= 40:
        return "执行 P0 + P1"
    elif total_effort <= 80:
        return "执行 P0 + 部分P1"
    else:
        return "只执行 P0，P1分批"
```

**输出**：
```
phase0-results/autonomous-optimization-plan.md
  - P0 清单（必做，总投入 ≤20h）
  - P1 清单（强烈建议，总投入 ≤40h）
  - P2 清单（可选，总投入 ≤40h）
  - 执行顺序（自动排序）
  - 预期效果（量化）
```

### 阶段 3：批量执行优化（自动化）

**目标**：按优先级自动执行所有优化

**执行方式**：
```yaml
自动化执行循环：
  for issue in sorted_issues:
    步骤 1: 读取优化方案
    步骤 2: 定位需要修改的文件
    步骤 3: 执行修改（代码/文档/测试）
    步骤 4: 自我验证（运行测试）
    步骤 5: 记录变更
    步骤 6: 如果验证失败 → 回滚 → 调整 → 重试
    步骤 7: 如果验证通过 → 提交 → 进入下一个
    
    中断条件：
      - 累计投入超过阈值（如80h）
      - 连续3次失败
      - 预期ROI降至<1
```

**安全机制**：
```yaml
每次修改前：
  - 创建Git分支
  - 备份原文件
  - 记录修改意图

每次修改后：
  - 运行测试套件
  - 验证Contract合规性
  - 检查是否引入新问题

如果失败：
  - 自动回滚
  - 记录失败原因
  - 调整方案
  - 重试（最多3次）
```

## 🚨 风险和缓解

### 风险 1：过度优化

**风险**：优化了不应该优化的地方

**缓解**：
- 严格的ROI门槛（>1）
- 每次优化前验证Contract
- 保持Git历史可回滚

### 风险 2：引入新问题

**风险**：修复旧问题，引入新问题

**缓解**：
- 每次修改后运行全量测试
- 95个测试用例回归
- 自动回滚机制

### 风险 3：投入超预期

**风险**：AI执行时间超出预期

**缓解**：
- 设置投入上限（80h）
- 超限自动暂停
- 请求人类决策

### 风险 4：方向偏离

**风险**：AI理解偏差，优化方向错误

**缓解**：
- Claude监督（方案C）
- 关键点人类确认
- 阶段性审查
