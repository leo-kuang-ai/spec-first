# 通知投递方案：读者题卡

只使用分到的那一份方案。请先独立回答，不需要熟悉 spec-first 或记住任何编号。每题写下答案、第一次翻到的章节、最后依据的原句。找不到就写「未找到」；若需要作者解释才能判断，请记录你想问的原话。

1. 你负责开发。要增加哪部分逻辑？哪些现有职责不能搬进去？能从文中确定要改的生产文件吗？
2. 你负责测试。用户在发送前改了偏好，以及系统无法取得偏好，分别应看到什么结果？现有用例能否分别发现这两种实现错误？
3. 客服说同一事件触发了两次。你会核对哪些记录、哪些实际结果？谁仍然有权决定订阅状态？
4. 你负责上线。启用前先完成什么？仅凭这份方案，可以决定怎样灰度以及何时回退吗？

记录格式：`题号｜答案｜先看哪一章｜依据原句或未找到｜是否需要解释`。可另记用时，但答得快不能抵消漏掉关键条件。
