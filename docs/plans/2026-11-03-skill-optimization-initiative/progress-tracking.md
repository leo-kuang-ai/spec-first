## Phase 1 优化范围（待 Phase 0 数据确认）

**决策原则**：
- 真实效果型候选：从 Layer 3 问题追查 Layer 2 衔接与 Layer 1 根因；不强迫单 Skill 内的确定性缺陷虚构跨阶段问题
- 已确认的独立源码缺陷可先处理，但本地检查不能证明真实任务收益；当前候选修改决定均待判定
- 优先级 = 影响面 × 严重程度
- 影响面 = 受影响任务数 / 总任务数
- 严重程度：导致返工 → P0；影响效率但不返工 → P1；仅浪费少量时间 → P2
