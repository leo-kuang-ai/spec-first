## v4 的核心突破

**v4（研发流程导向）**彻底转变了方法论：

### 起点改变

```
v1-v3: 列出 Skill → 选若干个优化
  ↓
v4: 选择真实任务 → 沿流程找阻力点 → 决定优化哪些 Skill
```

### 关注点改变

```
v1-v3: 单个 Skill 的性能/质量指标
  ↓
v4: 端到端交付质量（正确率、返工率、用户介入）
```

### Phase 0 改变

```
v1-v3: 代码质量评估、需求遗漏分析、审查有效性
  ↓
v4: 11 个真实任务的端到端流程追踪
```

### 优化范围改变

```
v1-v3: 预设 12-15 项
  ↓
v4: 动态决定（可能更多或更少）
```

## 如何使用这些历史文档

### 当你想理解...

- **为什么要做 Skill 优化？** → 读 v1
