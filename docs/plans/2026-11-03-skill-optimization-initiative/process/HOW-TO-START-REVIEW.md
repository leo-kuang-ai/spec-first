# 如何启动新一轮 Skill 审查

版本：v2.0 · 更新日期：2026-11-04

唯一执行规则为 [Skill 审查 Workflow](REVIEW-EXECUTION-WORKFLOW.md)。本页只帮助确定入口和首批工作，不复制验收规则；历史报告中的分数、完成标记和覆盖率不自动成为本轮结论。

## 选择本轮目标

| 目标 | 类型 | 主要交付 |
|---|---|---|
| 判断优化方案是否合理 | 方案评估 | 范围、可行性、风险与证据设计判断 |
| 检查指定 Skill 或具体机制 | 定向 Skill 审查 | 指定范围的源码、消费者与行为证据 |
| 系统审查 Skill 并判断交付是否可靠 | 完整 Skill 审查 | 全范围清单、三层质量、四层证据、发现与验收结论 |
| 一次跑完全部 Skill 的结构、行为与成本检查 | 全量单次审查 | 按 [FULL-REVIEW-ONE-PASS.md](FULL-REVIEW-ONE-PASS.md) 的 S0–S8；收益未验证 |
| 核实已修复的问题是否关闭 | 修复复验 | 原问题复现依据、修改后的回归与消费者证据 |

“新一轮 Skill 审查”默认采用完整 Skill 审查。对象以用户明确范围为准；未限定时清点当前 `skills/`，不沿用历史数量。先从主链路做一批校准，不能用该批结果代表全范围。

## 首批工作

1. 读取 workflow 第 1–3 节，记录目标 repo、用户目标、范围、授权、源码身份、实际宿主与模型、预算、验收口径。
2. 通过 `rg --files skills` 获取当前源码入口与引用；读取对应 `SKILL.md` 和必需 references，登记未读条件分支。读取 [core/06](../core/06-mainline-baseline.md) 定向到消费者，再回当前源码确认。
3. 从 [core/00](../core/00-goals-and-success-criteria.md)、[core/05](../core/05-optimization-dimensions-with-trends.md)、[core/12](../core/12-phase05-skill-deep-dive.md)取得目标、八维和深读要求，按 workflow 的来源适配表处理历史冲突。
4. 选择一个范围内 Skill，完成源码、适用维度、相关交接、场景设计和必要验证。工具/模型能力不足时交付已有证据与缺口，不能填成通过。
5. 使用[报告模板](ITERATION-REVIEW-TEMPLATE.md)，在本轮唯一目录 `reviews/runs/<日期>-<主题>/` 下记录 `report.md` 与必要 `evidence/`。目录相对 initiative 根，同名时另取后缀；不得覆盖旧轮。
6. 用首批结果校准判据、证据采集和成本，按 workflow 第 3 节「从试点推算全量规模」写出估算；超预算时向 owner 给出收缩选项，再按风险完成剩余对象。失败、未知、排除样本都保留；预算不足时明确剩余范围。
7. 需要声称收益时，先按 workflow 第 7 节固定任务清单与判据，再做同任务的基线 SHA / 候选 SHA 配对运行；只有候选侧数据时收益记未验证。

## 可以直接使用的请求示例

以下是用户可采用的请求模板，文档里的示例本身不构成任何授权。

```text
按 process/REVIEW-EXECUTION-WORKFLOW.md v2 开展新一轮完整 Skill 审查。
目标仓库为 spec-first，范围为当前 skills/ 全部入口及其相关消费者。
先完成一项主链路试点，再分批推进全部范围。
核对源码、三层质量目标、四层证据和适用 H/ML 场景，输出可回源报告。
本轮允许必要的本地证据产物与隔离验证；不要修改被审 Skill 或 runtime，
不要提交、推送、发布。需要未授权的付费或外部数据传输时，先完成独立本地工作。
```

若只审查五个主链路 Skill，在请求里明确名称；不要把“完整”误解释为扩大用户点名范围。新一轮实施授权与审查授权分开核对，已明确的授权无需重复确认。

## 结束时必须看什么

交付同时说明：审查执行 `complete/partial/blocked`、被审对象结论、收益结论，以及未完成项。具体判据只维护在 workflow 第 9 节。

- 完成了源码阅读，不等于完成了行为验证。
- 运行了 fixture，不等于真实任务效果已经证明。
- 发现关键缺陷，仍可以完成一次充分审查，但被审对象不能通过。
- 没有有效问题，可以保持现状；不为凑发现数量修改 Skill。

[流程图](REVIEW-WORKFLOW-DIAGRAMS.md)用于导航；[旧覆盖分析](../analysis/CORE-REVIEW-DIMENSIONS-COVERAGE.md)用于发现待核验线索，不能直接复用其完成率。
