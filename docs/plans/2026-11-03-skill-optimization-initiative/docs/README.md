## 🎯 重组原则

1. **职责分离**
   - core/：方案本身（怎么做）
   - reviews/：方案评审（做得如何）
   - docs/：元文档（关于项目的文档）

2. **根目录极简**
   - 只保留 README.md（总入口）
   - 所有其他文档归档到子目录

3. **可扩展性**
   - 为 Phase 0/1 结果预留目录
   - 清晰的目录结构便于后续维护
