# 安装指南

本指南提供 Spec-First 的详细安装步骤,包括不同平台和场景的安装方法。

## 📋 系统要求

### 必需软件

| 软件 | 最低版本 | 用途 | 安装链接 |
|------|---------|------|---------|
| Claude Code | 最新版 | 运行环境 | [官方文档](https://docs.anthropic.com/en/docs/claude-code) |
| Git | 2.0+ | 版本控制 | [下载](https://git-scm.com/) |
| Bun | 1.0+ | JavaScript 运行时 | [安装指南](https://bun.sh/) |
| Node.js | 18+ | 仅 Windows 需要 | [下载](https://nodejs.org/) |

### 系统支持

| 操作系统 | 支持状态 | 备注 |
|---------|---------|------|
| macOS | ✅ 完全支持 | 推荐 |
| Linux | ✅ 完全支持 | - |
| Windows | ⚠️ 部分支持 | 需要 Node.js |

### 硬件要求

- **内存**: 最低 4GB,推荐 8GB+
- **磁盘**: 至少 500MB 可用空间
- **网络**: 需要稳定的网络连接

## 🚀 安装方法

### 方法 1: 标准安装 (推荐)

适用于 Claude Code 用户。

#### macOS / Linux

```bash
# 1. 克隆仓库到 Claude 技能目录
git clone https://github.com/sunrain520/spec-first.git ~/.claude/skills/spec-first

# 2. 进入目录
cd ~/.claude/skills/spec-first

# 3. 运行安装脚本
./setup

# 可选：指定英文输出
# ./setup --lang en
```

#### Windows

```powershell
# 使用 PowerShell
git clone https://github.com/sunrain520/spec-first.git $env:USERPROFILE\.claude\skills\spec-first
cd $env:USERPROFILE\.claude\skills\spec-first
.\setup
```

### 方法 2: 自动安装 (最简单)

在 Claude Code 中直接说:

```
安装 spec-first
```

Claude 会自动执行所有安装步骤。

### 方法 3: 多平台安装

如果你同时使用 Claude Code 和 Codex:

```bash
# 1. 克隆到临时目录
git clone https://github.com/sunrain520/spec-first.git ~/spec-first-temp

# 2. 运行自动检测安装
cd ~/spec-first-temp
./setup --host auto

# 3. 清理临时目录
cd ~
rm -rf spec-first-temp
```

这会自动安装到:
- `~/.claude/skills/spec-first` (如果 Claude Code 存在)
- `~/.codex/skills/spec-first` (如果 Codex 存在)

### 方法 4: 项目本地安装

将 Spec-First 添加到特定项目,让团队成员自动获得:

```bash
# 在你的项目根目录
cd /path/to/your/project

# 1. 复制到项目
cp -Rf ~/.claude/skills/spec-first .claude/skills/spec-first

# 2. 移除 .git 目录 (避免子模块问题)
rm -rf .claude/skills/spec-first/.git

# 3. 在项目中运行安装
cd .claude/skills/spec-first
./setup

# 4. 提交到版本控制
cd ../..
git add .claude/skills/spec-first
git commit -m "Add spec-first to project"
git push
```

## 🔧 安装后配置

### 0. 语言配置

spec-first 默认使用**中文**输出（技术术语和代码标识符保持英文原文）。安装时可指定语言：

```bash
# 中文（默认）
./setup

# 英文
./setup --lang en
```

安装后切换语言：

```bash
# 切换为中文
echo "zh" > ~/.spec-first/lang

# 切换为英文
echo "en" > ~/.spec-first/lang

# 重新生成 SKILL.md 文件
cd ~/.claude/skills/spec-first && bun run gen:skill-docs
```

### 1. 配置 CLAUDE.md (推荐)

在项目根目录的 `CLAUDE.md` 中添加:

```markdown
## Spec-First 技能

本项目使用 Spec-First 技能集进行开发。

### 可用技能

#### 规划类
- `/brainstorm` - 头脑风暴模式的产品规划
- `/plan-ceo-review` - CEO 模式审查
- `/plan-eng-review` - 工程经理模式审查
- `/plan-design-review` - 设计师模式审查

#### 开发类
- `/review` - 代码审查
- `/qa` - QA 测试和修复
- `/qa-only` - 仅 QA 报告
- `/investigate` - 系统化调试

#### 部署类
- `/ship` - 自动发布流程
- `/land-and-deploy` - 合并和部署
- `/canary` - 部署后监控
- `/benchmark` - 性能回归检测

#### 安全类
- `/careful` - 危险命令警告
- `/freeze` - 限制编辑范围
- `/guard` - 完整安全模式

#### 工具类
- `/browse` - 浏览器自动化
- `/design-review` - 设计审查
- `/retro` - 周报和回顾
- `/document-release` - 文档更新

### 浏览器交互

**重要**: 使用 `/browse` 技能进行所有浏览器交互,不要使用 `mcp__claude-in-chrome__*` 工具。

### 故障排除

如果技能无法运行:
```bash
cd .claude/skills/spec-first
./setup
```
```

### 2. 验证安装

```bash
# 检查技能目录
ls ~/.claude/skills/spec-first/

# 检查 bin 命令
ls ~/.claude/skills/spec-first/bin/

# 检查 browse 二进制
ls ~/.claude/skills/spec-first/browse/dist/
```

应该看到:
- `bin/` - 包含 `spec-first-*` 命令
- `browse/dist/browse` - 浏览器自动化二进制
- 各个技能目录 - `brainstorm/`, `review/`, 等

### 3. 测试安装

在 Claude Code 中运行:

```
/brainstorm
```

如果看到交互式问答开始,说明安装成功!

## ❓ 安装问题

### 问题 1: 权限错误

**错误信息**: `Permission denied`

**解决方案**:
```bash
chmod +x ~/.claude/skills/spec-first/setup
chmod +x ~/.claude/skills/spec-first/bin/*
```

### 问题 2: Bun 未安装

**错误信息**: `bun: command not found`

**解决方案**:
```bash
# macOS/Linux
curl -fsSL https://bun.sh/install | bash

# 重启终端后重试
```

### 问题 3: Playwright 安装失败

**错误信息**: Playwright browser installation failed

**解决方案**:
```bash
cd ~/.claude/skills/spec-first
bunx playwright install chromium
```

### 问题 4: Windows 路径问题

**症状**: 路径包含空格导致失败

**解决方案**: 安装到不含空格的路径,或使用短路径名。
