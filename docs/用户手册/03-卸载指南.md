# 卸载指南

本指南提供完整的卸载步骤,帮助你完全移除 Spec-First。

## ⚠️ 卸载前须知

### 卸载影响

卸载 Spec-First 会:
- ✅ 删除所有技能文件
- ✅ 删除配置文件
- ✅ 删除浏览器二进制文件
- ❌ **不会**删除你的项目文件
- ❌ **不会**删除设计文档 (`~/.spec-first/projects/`)
- ❌ **不会**删除分析数据 (`~/.spec-first/analytics/`)

### 保留数据

如果你想保留以下数据,请在卸载前备份:

```bash
# 设计文档
cp -R ~/.spec-first/projects ~/spec-first-projects-backup

# 分析数据
cp -R ~/.spec-first/analytics ~/spec-first-analytics-backup
```

## 🗑️ 卸载步骤

### 方法 1: 完全卸载 (推荐)

删除所有 Spec-First 相关文件和数据:

```bash
# 1. 删除 Claude Code 安装
rm -rf ~/.claude/skills/spec-first

# 2. 删除 Codex 安装 (如果存在)
rm -rf ~/.codex/skills/spec-first

# 3. 删除用户数据和配置
rm -rf ~/.spec-first

# 4. 删除项目本地安装 (如果有)
# 在你的项目目录中:
rm -rf .claude/skills/spec-first
rm -rf .agents/skills/spec-first
```

### 方法 2: 仅卸载程序文件

保留用户数据,仅删除程序:

```bash
# 1. 删除 Claude Code 安装
rm -rf ~/.claude/skills/spec-first

# 2. 删除 Codex 安装 (如果存在)
rm -rf ~/.codex/skills/spec-first

# 保留:
# ~/.spec-first/ (用户数据)
```

### 方法 3: 卸载特定项目

仅从某个项目中移除:

```bash
# 在项目根目录
cd /path/to/your/project

# 删除项目本地安装
rm -rf .claude/skills/spec-first
rm -rf .agents/skills/spec-first

# 可选: 从 CLAUDE.md 中删除相关配置
# 编辑 CLAUDE.md,移除 Spec-First 相关部分
```

## 🧹 清理残留

### 清理 CLAUDE.md 配置

从项目的 `CLAUDE.md` 中删除:

```markdown
## Spec-First 技能
... (所有相关内容)
```

### 清理符号链接

```bash
# 检查并删除可能的符号链接
find ~/.claude/skills -type l -name "spec-first" -delete
find ~/.codex/skills -type l -name "spec-first" -delete
```

### 清理 PATH (如果添加过)

如果你在 shell 配置文件中添加了 PATH:

```bash
# 编辑 ~/.bashrc, ~/.zshrc, 或 ~/.bash_profile
# 删除类似这样的行:
# export PATH="$PATH:~/.claude/skills/spec-first/bin"
```

## ✅ 验证卸载

### 1. 检查安装目录

```bash
# 应该返回 "No such file or directory"
ls ~/.claude/skills/spec-first
ls ~/.codex/skills/spec-first
```

### 2. 检查命令

```bash
# 应该返回 "command not found"
which spec-first-slug
which spec-first-review-read
```

### 3. 测试 Claude Code

打开 Claude Code,输入:

```
/office-hours
```

应该提示技能不存在。

## 🔄 重新安装

如果你想重新安装:

```bash
# 完全新安装
git clone https://github.com/your-org/spec-first.git ~/.claude/skills/spec-first
cd ~/.claude/skills/spec-first
./setup
```

详见 [安装指南](./02-安装指南.md)。

## 📊 卸载统计

### 卸载后释放的空间

| 组件 | 大小 |
|------|------|
| 程序文件 | ~50 MB |
| 浏览器二进制 | ~10 MB |
| 依赖包 | ~100 MB |
| 用户数据 | ~1-50 MB |
| **总计** | **~160-210 MB** |

### 保留的数据

如果选择保留用户数据:

| 数据类型 | 位置 | 大小 |
|---------|------|------|
| 设计文档 | `~/.spec-first/projects/` | 1-10 MB |
| 分析数据 | `~/.spec-first/analytics/` | < 1 MB |
| 会话记录 | `~/.spec-first/sessions/` | < 5 MB |

## ❓ 常见问题

### Q: 卸载后能恢复吗?

A: 可以重新安装,但用户数据如果删除了就无法恢复。建议卸载前备份。

### Q: 卸载会影响我的项目吗?

A: 不会。卸载只删除 Spec-First 程序文件,不影响你的项目代码。

### Q: 如何只卸载某个版本?

A: Spec-First 目前不支持多版本共存,卸载会删除所有版本。

### Q: 卸载后还能使用 Claude Code 吗?

A: 完全可以。Spec-First 只是 Claude Code 的技能扩展,卸载不影响 Claude Code 本身。

### Q: 项目中的 `.spec-first/` 目录要删除吗?

A: 那是项目数据目录,包含 QA 报告、性能基线等。如果不再需要,可以删除:

```bash
rm -rf .spec-first/
```
