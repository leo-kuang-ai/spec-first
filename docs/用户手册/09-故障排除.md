# 故障排除

本指南帮助你诊断和解决使用 Spec-First 时遇到的常见问题。

## 🔍 诊断流程

### 第一步: 快速诊断

遇到问题时,先运行这些诊断命令:

```bash
# 1. 检查版本
cd ~/.claude/skills/spec-first
git log --oneline -1

# 2. 检查文件完整性
ls -la ~/.claude/skills/spec-first/bin/
ls -la ~/.claude/skills/spec-first/browse/dist/

# 3. 检查配置
cat ~/.spec-first/config.json 2>/dev/null || echo "Config not found"

# 4. 重新安装
./setup
```

### 第二步: 查看日志

```bash
# Spec-First 日志
tail -100 ~/.spec-first/logs/spec-first.log

# Claude Code 日志 (如果有)
tail -100 ~/.claude/logs/claude-code.log
```

## ❌ 安装问题

### 问题 1: Clone 失败

**症状**:
```
fatal: unable to access 'https://github.com/.../spec-first.git/':
Failed to connect to github.com
```

**诊断**:
```bash
# 测试网络
ping github.com

# 测试 Git 连接
ssh -T git@github.com
```

**解决方案**:
```bash
# 方案 1: 使用 SSH
git clone git@github.com:sunrain520/spec-first.git ~/.claude/skills/spec-first

# 方案 2: 使用镜像
git clone https://mirror.url/spec-first.git ~/.claude/skills/spec-first

# 方案 3: 手动下载
# 下载 ZIP,解压到 ~/.claude/skills/spec-first/
```

---

### 问题 2: Setup 脚本失败

**症状**:
```
Error: bun: command not found
```

**诊断**:
```bash
# 检查 Bun
which bun
bun --version

# 检查 PATH
echo $PATH
```

**解决方案**:
```bash
# 安装 Bun
curl -fsSL https://bun.sh/install | bash

# 重启终端
source ~/.bashrc  # 或 ~/.zshrc

# 验证
bun --version
```

---

### 问题 3: Playwright 安装失败

**症状**:
```
Error: Executable doesn't exist at ~/.cache/ms-playwright/...
```

**诊断**:
```bash
# 检查 Playwright
bunx playwright --version

# 检查浏览器
ls ~/.cache/ms-playwright/
```

**解决方案**:
```bash
# 手动安装 Chromium
cd ~/.claude/skills/spec-first
bunx playwright install chromium

# 如果失败,尝试
npm install -g playwright
playwright install chromium

# Windows 用户可能需要
npx playwright install-deps chromium
```

---

### 问题 4: 权限错误

**症状**:
```
bash: ./setup: Permission denied
```

**解决方案**:
```bash
# 给予执行权限
chmod +x ~/.claude/skills/spec-first/setup
chmod +x ~/.claude/skills/spec-first/bin/*

# 如果目录权限有问题
chmod -R 755 ~/.claude/skills/spec-first/
```

## 🎯 技能问题

### 问题 5: 技能未找到

**症状**:
```
Claude: I'm not sure what you mean by "/brainstorm"
```

**诊断**:
```bash
# 1. 检查安装
ls ~/.claude/skills/spec-first/

# 2. 检查技能文件
ls ~/.claude/skills/spec-first/brainstorm/

# 3. 检查 SKILL.md
cat ~/.claude/skills/spec-first/brainstorm/SKILL.md
```

**解决方案**:
```bash
# 重新运行 setup
cd ~/.claude/skills/spec-first
./setup

# 重启 Claude Code

# 如果还是不行,重新安装
rm -rf ~/.claude/skills/spec-first
git clone https://github.com/sunrain520/spec-first.git ~/.claude/skills/spec-first
cd ~/.claude/skills/spec-first
./setup
```

---

### 问题 6: Browse 技能失败

**症状**:
```
Error: browse binary not found
```

**诊断**:
```bash
# 检查二进制
ls -la ~/.claude/skills/spec-first/browse/dist/browse

# 测试运行
~/.claude/skills/spec-first/browse/dist/browse --version
```

**解决方案**:
```bash
# 重新构建
cd ~/.claude/skills/spec-first
bun run build

# 验证
./browse/dist/browse --version

# 如果失败,清理后重建
rm -rf browse/dist node_modules
bun install
bun run build
```

---

### 问题 7: QA 无法连接

**症状**:
```
Error: Failed to navigate to http://localhost:3000
```

**诊断**:
```bash
# 检查应用是否运行
curl http://localhost:3000

# 检查端口
lsof -i :3000

# 检查进程
ps aux | grep your-app
```

**解决方案**:
```bash
# 1. 确认应用正在运行
npm run dev  # 或你的启动命令

# 2. 使用正确的 URL
/qa http://localhost:3000  # 不是 localhost:3000

# 3. 检查防火墙
# macOS: 系统偏好设置 > 安全性与隐私 > 防火墙

# 4. 尝试 127.0.0.1
/qa http://127.0.0.1:3000
```

### 问题 8: Ship 技能报错

**症状**:
```
Error: You're on the base branch
```

**诊断**:
```bash
# 检查当前分支
git branch

# 检查状态
git status
```

**解决方案**:
```bash
# 1. 创建功能分支
git checkout -b feature/my-feature

# 2. 提交更改
git add -A
git commit -m "feat: my feature"

# 3. 运行 /ship
/ship
```

## ⚡ 性能问题

### 问题 9: 技能运行缓慢

**诊断**:
```bash
# 检查系统资源
top

# 检查磁盘空间
df -h

# 检查网络
ping google.com
```

**解决方案**:
```bash
# 1. 使用快速模式
/qa --quick
/review --quick

# 2. 清理缓存
rm -rf ~/.spec-first/cache

# 3. 清理旧数据
find ~/.spec-first -name "*.old" -delete

# 4. 限制并发
# 不要同时运行多个重量级技能
```

---

### 问题 10: 内存占用高

**诊断**:
```bash
# 检查内存占用
ps aux | grep spec-first

# 检查 Node/Bun 进程
ps aux | grep -E "node|bun"
```

**解决方案**:
```bash
# 1. 清理数据
rm -rf ~/.spec-first/analytics/*.old
rm -rf ~/.spec-first/sessions/*.old

# 2. 限制日志大小
# 编辑 ~/.spec-first/config.json
{
  "maxLogSize": "10MB"
}

# 3. 重启 Claude Code
```

## 🔒 权限和安全问题

### 问题 11: Git 操作失败

**症状**:
```
Error: Permission denied (publickey)
```

**诊断**:
```bash
# 检查 SSH key
ssh -T git@github.com

# 检查 Git 配置
git config --list
```

**解决方案**:
```bash
# 1. 配置 SSH key
ssh-keygen -t ed25519 -C "your@email.com"
cat ~/.ssh/id_ed25519.pub
# 添加到 GitHub Settings > SSH Keys

# 2. 或使用 HTTPS
git remote set-url origin https://github.com/sunrain520/spec-first.git

# 3. 配置 Git 凭据
git config --global credential.helper cache
```

---

### 问题 12: 文件写入失败

**症状**:
```
Error: EACCES: permission denied, open '/path/to/file'
```

**解决方案**:
```bash
# 1. 检查文件权限
ls -la /path/to/file

# 2. 修改权限
chmod 644 /path/to/file

# 3. 或修改所有者
chown $USER:$USER /path/to/file

# 4. 检查目录权限
ls -la /path/to/
```

## 🌐 网络问题

### 问题 13: API 调用失败

**症状**:
```
Error: Network request failed
```

**诊断**:
```bash
# 测试网络
curl -I https://api.anthropic.com

# 检查代理
env | grep -i proxy
```

**解决方案**:
```bash
# 1. 检查网络连接
ping google.com

# 2. 禁用代理 (如果不需要)
unset http_proxy
unset https_proxy

# 3. 或配置代理
export https_proxy=http://your-proxy:port

# 4. 检查防火墙设置
```

---

### 问题 14: 超时错误

**症状**:
```
Error: Timeout of 30000ms exceeded
```

**解决方案**:
```bash
# 1. 增加超时
/qa --timeout 60000

# 2. 检查网络速度
speedtest-cli

# 3. 使用更快的网络
# 或在配置中调整
# ~/.spec-first/config.json
{
  "timeout": 60000
}
```

## 🔄 更新问题

### 问题 15: 更新后不工作

**症状**: 更新后技能失败。

**诊断**:
```bash
# 检查版本
cd ~/.claude/skills/spec-first
git log --oneline -5

# 检查文件变化
git diff HEAD~1 HEAD
```

**解决方案**:
```bash
# 1. 清理重建
cd ~/.claude/skills/spec-first
rm -rf node_modules browse/dist
bun install
bun run build
./setup

# 2. 如果还是不行,全新安装
cd ~
rm -rf ~/.claude/skills/spec-first
git clone https://github.com/sunrain520/spec-first.git ~/.claude/skills/spec-first
cd ~/.claude/skills/spec-first
./setup
```

---

### 问题 16: 版本冲突

**症状**:
```
Error: Version mismatch
```

**解决方案**:
```bash
# 1. 检查版本
cd ~/.claude/skills/spec-first
cat VERSION

# 2. 更新到最新
git fetch origin
git checkout master
git pull origin master
./setup

# 3. 或回滚到稳定版本
git checkout v1.3.1.1
./setup
```

## 📊 日志和调试

### 启用详细日志

```bash
# 设置环境变量
export SPEC_FIRST_DEBUG=true
export SPEC_FIRST_LOG_LEVEL=debug

# 运行技能
/brainstorm
```

### 查看日志

```bash
# 主日志
tail -f ~/.spec-first/logs/spec-first.log

# 技能日志
tail -f ~/.spec-first/logs/skills.log

# 错误日志
tail -f ~/.spec-first/logs/errors.log
```

### 收集诊断信息

```bash
# 创建诊断报告
cat > /tmp/spec-first-diagnostic.sh << 'EOF'
#!/bin/bash
echo "=== Spec-First Diagnostic Report ==="
echo "Date: $(date)"
echo ""
echo "=== Version ==="
cd ~/.claude/skills/spec-first && git log --oneline -1
echo ""
echo "=== System ==="
uname -a
echo ""
echo "=== Bun ==="
bun --version
echo ""
echo "=== Node ==="
node --version 2>/dev/null || echo "Node not found"
echo ""
echo "=== Files ==="
ls -la ~/.claude/skills/spec-first/bin/
ls -la ~/.claude/skills/spec-first/browse/dist/
echo ""
echo "=== Config ==="
cat ~/.spec-first/config.json 2>/dev/null || echo "Config not found"
echo ""
echo "=== Recent Logs ==="
tail -20 ~/.spec-first/logs/spec-first.log 2>/dev/null || echo "Log not found"
EOF

chmod +x /tmp/spec-first-diagnostic.sh
/tmp/spec-first-diagnostic.sh > /tmp/spec-first-diagnostic.txt
cat /tmp/spec-first-diagnostic.txt
```


     - 实际行为

   - 诊断报告 (`diagnostic.txt`)
   - 错误日志
   - 截图 (如果有)
