## 版本命名规则

### 主版本号 (MAJOR)

当你做了不兼容的 API 修改

**示例**:
- 1.x.x → 2.0.0
- 重构技能系统
- 移除核心功能

### 次版本号 (MINOR)

当你做了向后兼容的功能性新增

**示例**:
- 1.0.x → 1.1.0
- 新增技能
- 新增配置选项

### 修订号 (PATCH)

当你做了向后兼容的问题修正

**示例**:
- 1.0.0 → 1.0.1
- Bug 修复
- 文档更新
- 性能优化

## 升级指南

### 从未安装 → 1.0.0

```bash
git clone https://github.com/sunrain520/spec-first.git ~/.claude/skills/spec-first
cd ~/.claude/skills/spec-first
./setup
```

### 未来版本升级

```bash
# 自动升级
/spec-first-upgrade

# 或手动升级
cd ~/.claude/skills/spec-first
git pull origin master
./setup
```
