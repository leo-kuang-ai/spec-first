# 快速开始指南

本指南将帮助你在 **10 分钟内** 完成从安装到第一次成功运行的完整流程。

## 📋 前置要求

在开始之前,请确保你的系统已安装:

- ✅ **Claude Code** - [安装指南](https://docs.anthropic.com/en/docs/claude-code)
- ✅ **Git** - [下载地址](https://git-scm.com/)
- ✅ **Bun** v1.0+ - [安装指南](https://bun.sh/)
- ✅ **Node.js** (仅 Windows 需要) - [下载地址](https://nodejs.org/)

验证安装:

```bash
# 检查 Git
git --version

# 检查 Bun
bun --version

# 检查 Node.js (Windows)
node --version
```

## 🚀 第一步: 安装 Spec-First (2 分钟)

### 方法 1: 自动安装 (推荐)

打开 Claude Code,复制粘贴以下命令:

```
安装 spec-first: 运行 git clone https://github.com/your-org/spec-first.git ~/.claude/skills/spec-first && cd ~/.claude/skills/spec-first && ./setup
```

Claude 会自动执行安装脚本。

### 方法 2: 手动安装

```bash
# 1. 克隆仓库
git clone https://github.com/your-org/spec-first.git ~/.claude/skills/spec-first

# 2. 进入目录
cd ~/.claude/skills/spec-first

# 3. 运行安装脚本
./setup
```

### 验证安装

```bash
# 检查技能目录
ls ~/.claude/skills/spec-first/

# 应该看到:
# bin/  browse/  careful/  freeze/  guard/  ...
```

## 🎯 第二步: 第一次运行 (3 分钟)

### 1. 打开 Claude Code

在你的项目目录中启动 Claude Code。

### 2. 运行你的第一个技能

输入:

```
/office-hours
```

### 3. 描述你的想法

当 Claude 询问时,描述你想要构建的产品或功能。例如:

```
我想构建一个每日简报应用,帮助用户管理多个日历,
自动更新事件信息,并生成每日任务摘要。
```

### 4. 体验完整流程

`/office-hours` 会:

1. ✅ 提出深入问题,了解真实痛点
2. ✅ 挑战你的前提假设
3. ✅ 生成 2-3 个实现方案
4. ✅ 创建设计文档
5. ✅ 为后续技能提供上下文

## 🔄 第三步: 完整工作流 (5 分钟)

### 1. 产品规划

```bash
# CEO 模式审查
/plan-ceo-review
```

这会:
- 重新思考问题
- 挑战范围
- 找到 10 倍产品

### 2. 工程规划

```bash
# 工程经理模式审查
/plan-eng-review
```

这会:
- 锁定架构
- 检查边缘情况
- 生成测试计划

### 3. 开始编码

Claude 会根据规划自动开始实现。

### 4. 代码审查

```bash
# 自动代码审查
/review
```

### 5. 质量保证

```bash
# QA 测试 (需要运行的应用)
/qa https://your-app.com

# 或仅报告模式
/qa-only https://your-app.com
```

### 6. 发布

```bash
# 创建 PR
/ship

# 合并和部署
/land-and-deploy
```

## 📊 预期结果

### 第一次运行后,你会得到:

1. ✅ **设计文档** - 保存在 `~/.spec-first/projects/`
2. ✅ **测试计划** - 详细的测试场景
3. ✅ **代码实现** - 根据设计生成
4. ✅ **质量报告** - QA 测试结果
5. ✅ **PR 链接** - 准备合并的 Pull Request

### 时间预估

| 步骤 | 预计时间 |
|------|---------|
| 安装 | 2 分钟 |
| 第一次运行 | 3 分钟 |
| 完整工作流 | 5-30 分钟 |
| **总计** | **10-35 分钟** |

## ❓ 常见问题

### Q: 安装失败怎么办?

A: 检查前置要求是否满足,然后查看 [故障排除](./09-故障排除.md)。

### Q: 技能无法运行?

A: 确保在 Claude Code 中运行,而不是普通终端。

### Q: 如何更新?

A: 运行 `/spec-first-upgrade` 或手动 `git pull`。

### Q: 如何卸载?

A: 查看 [卸载指南](./03-卸载指南.md)。
