## 摘要

本版为 `spec-first` 的稳定性更新，从 v1.15.0 升级到 v1.15.1。该 patch 版本的唯一对外行为变化是修复 `spec-first init` 的目标解析逻辑：当前目录没有 `.git` marker 但能发现 child repos 时，按父 workspace 边界处理，不再被错误提升到无关的祖先 Git 仓库根；普通 Git 仓库子目录仍定位最近 Git 根。其余为文档收口与配置可移植性调整，不影响 npm 包功能。

## 亮点

- 修复嵌套父 workspace 场景下的 `spec-first init` 目标解析问题，避免将非 Git workspace 错误提升到祖先仓库根
- 补充 8 月文档收口：capability-evolution 决策台账、优化执行序列 Plan、外部 engineering skill 能力映射、CodeGraph 安装诊断分析、v4.0 首场 PPT 讲稿 draft

## 修复

- **`spec-first init` 目标解析**：当前目录无 `.git` marker 但能发现 child repos 时，优先按父 workspace 边界处理，不再被 `findGitRoot` 提升到无关祖先 Git 仓库根。普通 Git 仓库子目录仍定位最近 Git 根。
- 同步 `package.json` 与 `package-lock.json` 版本字段，避免 `npm ci` 版本漂移

## 升级注意事项

- 本版为 patch 升级，无破坏性变更，可直接从 v1.15.0 升级
- `.claude/settings.json` hook 参数已改为 `CLAUDE_PROJECT_DIR` 相对解析（不在 npm 包内，仅影响仓库本身的 generated runtime）
