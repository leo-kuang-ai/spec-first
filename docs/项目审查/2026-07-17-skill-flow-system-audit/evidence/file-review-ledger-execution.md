# Skill 关系逐文件审查台账（执行链路分区）

本台账只判断 Skill 之间的 route、handoff、caller、consumer、authority、failure-return、internal-helper 关系；不扩展为普通代码质量审查。CodeGraph 仅用于候选导航，所有判断均以本台账列出的当前源码行回源确认。

跨分区收口修正：fresh-source 场景后完成 35/35 package dispatch-authority 对账；`spec-compound`、`spec-compound-refresh`、`spec-resolve-pr-feedback` 等局部流程即使其他 route/return 字段已正确登记，仍存在共享 authorization/capability fallback 未继承问题，统一见 SF-27 与 [edge-ledger.md §9](edge-ledger.md)。本修正不改变本台账 85/85 分母。

判定记号：`正确` 表示关系方向、权威和失败返回在本分区源码内相互一致；`无跨 Skill 关系` 表示该文件只服务本 Skill 内部语义；`候选问题` 必须在文末给出反证与待交叉核验项。
