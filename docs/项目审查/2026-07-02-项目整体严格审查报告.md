## 2. 项目定位与 Harness 判断

项目一句话定位：`spec-first` 是面向 Claude Code 与 Codex 的 repo-backed AI Coding Harness，把一次性 AI coding 对话转成需求、计划、任务、执行、审查、证据和知识沉淀的工程闭环。

| 判断项 | 结论 |
|---|---|
| 是否具备 Harness | 部分到明确具备。主链路与治理骨架成立，但真实 outcome 评测不足 |
| 当前层级 | AI Coding Harness 雏形完整，向工程级 Harness 过渡 |
| 与 Prompt Collection 区别 | 不以 prompt 数量为核心，而以 repo-local artifacts、runtime catalog、source/runtime 边界、verification facts 为核心 |
| 与 Skill Toolkit 区别 | skills 之间有 workflow admission、handoff、runtime generation、governance records 和 tests |
| 与普通 Workflow 区别 | 具备 Evidence、Evaluation、Knowledge、Governance 四类闭环合同，不只是步骤清单 |
| 距企业级差距 | 真实用户摩擦数据、outcome 指标、团队治理材料、知识复用率、语义评测闭环 |
